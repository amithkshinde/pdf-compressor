    How can I be sure my file stays private?
    • Your file is read and shrunk by code running in this browser tab. The app has no server that could receive it.
    • The page tells your browser to block every connection except to this site, so even a bug couldn't send a file elsewhere.
    • Check it yourself: turn on airplane mode after the page loads and it still works. Or open your browser's Network tab and watch: nothing is sent when you pick a file.
    • The code is open: github.com/amithkshinde/pdf-compressor
    • The only thing measured is how many people visit the page, never anything about files.
